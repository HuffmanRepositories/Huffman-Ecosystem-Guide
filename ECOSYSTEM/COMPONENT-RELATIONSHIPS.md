# Component Relationships

The ecosystem is a collection of separately maintained projects. Do not assume dependencies or runtime integration unless documented and tested.

Suggested exploration:
- Compatibility core and compatibility fixtures
- Compatibility semantics and metrics interoperability
- Memory portability and privacy/data handling
- Evaluation oracle integrity and evaluation workflows
- Retry/idempotency fixtures and tool execution behavior
- Delegation scope fixtures and delegated agent boundary
- Delegated budget fixtures and budget accounting and limits

Record actual tested combinations, versions, expected outcomes, and limitations. A fixture set is not an enforcement engine.
