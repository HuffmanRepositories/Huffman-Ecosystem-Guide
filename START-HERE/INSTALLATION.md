# Installation and Setup

This guide must be finalized after checking each repository's current language/runtime and release status.

General safe setup:
1. Use a disposable local development environment.
2. Read the target repository README and license.
3. Pin dependencies and record versions.
4. Avoid secrets and production credentials.
5. Run the project's documented test suite.
6. Record command, environment, commit SHA, and result.
7. Do not deploy examples into production without a separate review.

Use repository-specific commands from the upstream README; do not invent installation commands.
