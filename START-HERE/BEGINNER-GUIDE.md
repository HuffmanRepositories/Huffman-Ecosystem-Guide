# Beginner Guide

## What is this ecosystem?
A collection of open-source specifications, interoperability materials, and synthetic fixtures intended to help people reason about AI-agent compatibility, evaluation, memory portability, delegation, retries, and budgets.

## Suggested learning path
1. Read the repository map and project status.
2. Start with Open-Agent-Compatibility.
3. Explore its fixture repository.
4. Read metrics interoperability (OARMI).
5. Explore specialized fixtures (P10–P14).
6. Run only local examples and synthetic fixtures.
7. Read security, privacy, and legal guidance before adapting to real systems.

## Important distinction
A test fixture demonstrates a scenario or expected behavior. It does not prove that a production agent, runtime, platform, or vendor enforces the behavior.
