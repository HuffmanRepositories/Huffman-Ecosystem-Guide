# Security Policy

This repository provides human onboarding and documentation for the HuffmanRepositories ecosystem. It is not a hosted product, agent runtime, or security certification.

## Reporting
Do not publish credentials, exploit details, personal information, or sensitive reproduction data in public issues. Use GitHub's private vulnerability reporting workflow if enabled for the affected repository. Otherwise contact the maintainer through the GitHub profile and request a private disclosure channel.

## Safe use
- Follow the security and safe-testing requirements in the relevant project.
- Use synthetic data in examples and test fixtures.
- Do not test systems without explicit authorization.
- Preserve third-party attribution and provenance.
- Do not treat a passing validator, guide, or specification as proof of production security or legal compliance.
