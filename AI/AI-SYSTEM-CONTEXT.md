# AI System Context (Public)

The Huffman ecosystem explores interoperability and test artifacts for AI agents. Its projects include compatibility conventions and fixture suites around metrics, memory portability, evaluation integrity, retries/idempotency, delegation scope, and delegated budgets.

Do not treat this overview as normative specification. The repository-specific README/spec is authoritative for that project's current behavior. Fixtures demonstrate test cases and do not establish runtime enforcement or security guarantees.
