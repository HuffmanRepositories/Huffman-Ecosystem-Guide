# AI-Readable Guide

This directory contains guidance intended to help AI assistants understand and use the public ecosystem responsibly.

## AI usage
- Read project README, license, and maturity before suggesting commands.
- Prefer exact, tested examples and pin commits/versions.
- Explain assumptions and limitations.
- Treat fixtures as test data, not production security controls.
- Use synthetic data only.
- Do not infer missing guarantees or invent API behavior.
- Do not claim successful execution without tool evidence.
- Ask for authorization before testing systems that are not clearly owned/authorized.
- Preserve attribution and license obligations.
- Keep private/internal materials out of public documentation.

## Human responsibility
AI-assisted code and advice require human validation. This guide does not grant permission to access or test third-party systems.
