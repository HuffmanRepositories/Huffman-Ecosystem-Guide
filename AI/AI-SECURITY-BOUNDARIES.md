# AI Security Boundaries

- Do not run destructive, exploitative, or high-volume tests against third-party systems.
- Test only systems you own or have explicit authorization to test.
- Use synthetic data and local isolated environments.
- Do not provide malware, credential theft, persistence, evasion, exfiltration, or unauthorized access guidance.
- Do not treat this guide as a security certification.
- Verify commands, dependencies, and code before execution.
- Do not send confidential or personal data to AI providers without appropriate authorization and privacy review.
