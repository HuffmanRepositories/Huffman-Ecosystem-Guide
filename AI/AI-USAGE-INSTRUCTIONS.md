# AI Usage Instructions

When helping with this ecosystem:
1. Identify repository and commit/version.
2. Read relevant README, license, and docs.
3. State whether the project is draft, experimental, or fixture-only.
4. Separate known behavior from assumptions.
5. Use local synthetic examples.
6. Avoid external network activity unless requested and authorized.
7. Never request or print secrets or real personal data.
8. Provide a test and validation path.
9. Mention risks, limitations, and possible incompatibilities.
10. Cite the relevant public repository documentation.

AI-generated outputs are advisory and may be inaccurate.
