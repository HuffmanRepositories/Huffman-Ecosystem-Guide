# Security Policy

## Scope
Security reports should concern vulnerabilities in this project's public repositories or published artifacts. Confirm the current maintainer contact before disclosure.

## Responsible reporting
- Do not publicly disclose unpatched vulnerabilities.
- Do not access, modify, or exfiltrate data that is not yours.
- Do not disrupt services or test third-party systems.
- Provide a concise report, affected version/commit, safe reproduction, impact, and redacted evidence.
- Avoid secrets and personal information in reports.

## Limitations
No project is guaranteed secure. Fixture suites do not necessarily implement production controls.
