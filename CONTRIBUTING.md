# Contributing

1. Read the code of conduct, security policy, and license.
2. Open an issue for substantial changes.
3. Use synthetic examples and avoid sensitive data.
4. Include reproducible tests and documentation.
5. Do not make security claims without evidence.
6. Do not disclose private internal testing material.
7. Maintainers review correctness, compatibility, safety, and licensing.

Contributions are not automatically accepted or production-ready.
